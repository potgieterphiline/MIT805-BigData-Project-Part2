Project Overview
This project uses PySpark to analyse NYC Yellow Taxi trip data from 2024 and 2025. It identifies night-time routes and zones with the lowest average travel speeds by transforming, grouping and aggregating trip records across route, location and time periods. The analysis demonstrates Spark’s distributed processing and DAG execution while providing insights into possible congestion, roadworks and operational inefficiencies.
